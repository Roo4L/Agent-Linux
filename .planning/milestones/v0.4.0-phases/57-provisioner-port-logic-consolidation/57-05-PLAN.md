<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PATH artefacts → every invocation mode's resolved PATH | These files define which `agentlinux`/`npm`/agent binary each of the six modes resolves; a wrong PATH ordering lets a `/usr/local/bin` shim shadow the user-owned binary (the self-update bug). |
| `<home>/.bashrc` marker block → non-interactive shells | The `--top` placement is what makes SSH/`sudo -u bash -c` pick up PATH before the skel early-return; a `--bottom` slip silently breaks those modes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-57-12 | Elevation | PATH ordering across artefacts | high | mitigate | User-owned prefixes FIRST in every artefact (`.npm-global/bin` ends first), so a stray `/usr/local/bin` shim cannot shadow a user-owned binary — the canonical self-update EoP bug (Pitfall 6). Task 1 asserts the ordering + the byte-identical PATH line. |
| T-57-13 | Tampering | `<home>/.bashrc` marker block | medium | mitigate | `ensure_marker_block --top` preserves user content outside the block AND places the guard before the skel non-interactive early-return (Pitfall 2) so SSH/`sudo -u bash -c` get the correct PATH; re-chown to <user>:<user> keeps it user-editable. |
| T-57-14 | Tampering | artefact-3/artefact-4 PATH drift | low | mitigate | The two PATH lines are built from ONE source expression + a test asserts byte-equality against the recipe_env canonical PATH, so a future edit cannot desync systemd's EnvironmentFile from cron's header. |
| T-57-SC | Tampering | crates.io installs (no new crates) | low | accept | No new dependencies this plan. |
</threat_model>
