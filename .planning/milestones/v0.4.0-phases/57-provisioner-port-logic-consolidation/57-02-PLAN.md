<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| invoker EUID → `require_root` → provision | The provisioner runs privileged systems I/O (useradd, chown, locale files); `require_root` ensures only EUID==0 proceeds — a non-root invoker exits 64 before any mutation. |
| `--user` / `AGENTLINUX_USER` → install-user name → useradd/chown argv | A malformed user name would flow into `useradd`/`chown`; the charset validation (`^[a-z][a-z0-9_-]*$`) + reject-system-account gate bound it before any mutation. |
| DOC02 body const → `<home>/CLAUDE.md` (user-owned) | Root writes a user-owned file; the marker block preserves user content outside it, and the re-chown to <user>:<user> prevents a root-owned file the user cannot edit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-57-04 | Elevation | `provision` dispatch (Pitfall 7) | high | mitigate | `provision` routes through `require_root` (EUID==0), NOT `guard_agent_user` (which would reject root AND, if bypassed the wrong way, could let a non-root invoker attempt privileged I/O). A non-root invoker exits 64 before any step runs. Task 1 asserts the guard. |
| T-57-05 | Elevation | install-user name → useradd/chown | high | mitigate | The install-user string is charset-validated (`^[a-z][a-z0-9_-]*$`) + rejected if a system account (UID<1000) BEFORE it reaches useradd/chown argv (ported `validate_user_name`/`user_adoptable`). |
| T-57-06 | Tampering | `<home>/CLAUDE.md` marker block | low | mitigate | `ensure_marker_block` replaces only the tagged block (user content survives); re-chown to <user>:<user> keeps the file user-editable. Task 2 asserts the byte-exact block + ownership. |
| T-57-SC | Tampering | crates.io installs (no new crates) | low | accept | No new dependencies this plan. |
</threat_model>
