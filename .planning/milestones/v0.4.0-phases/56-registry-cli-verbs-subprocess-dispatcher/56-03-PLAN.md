Wave 2 — the mutating verbs, where the dispatcher (VERB-02) + the env contract
(VERB-03) are exercised end-to-end on REAL recipes for the first time:

1. **The remaining adapters:** `probe.rs` (installed-version fs read of the
   installed package.json), `npm.rs` (`queryGlobalNpm`/`queryNpmViewLatest` via

   (pure gates) → dispatch install.sh (streaming) through the dispatcher; the
   `[DRY-RUN]`/`[REUSE-03]`/`[REMEDIATE-04]`/`▸ installing`/`installed`/`no-op`
   literals; the full 64/65/1/propagated exit map; the `--version` shadow +
   non-TTY `--yes` gate.
3. **`remove`** — dispatch uninstall.sh streaming; `▸ removing`/`removed`; the
   64/1/no-op exit map.
4. **`upgrade`** — the padded 7-column DivergenceReport table (or `--json`);
   `compute_divergence`/`resolve_latest_for`/`shouldReinstall` + reconcile-loop
   dispatch of install.sh; per-entry `continue` on failure (never abort).

(catalog/sentinel/cache/guard); they add only probe/npm/rewire. Parity is
pinned by the TS command unit tests + green 40-registry-cli / 23-install-user /
50-agents (non-network-gated) on the Rust build.

Purpose: complete VERB-01 across all six verbs and prove VERB-02/VERB-03 on
real recipe dispatch.
Output: probe/npm/rewire adapters + install/remove/upgrade verb modules +
main.rs routing. The pure core is untouched.
