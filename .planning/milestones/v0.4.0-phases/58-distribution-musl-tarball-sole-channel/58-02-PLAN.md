<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| downloaded tarball → `exec <bin> provision` | The sha256-before-exec gate (install.sh:204-209) MUST fire before the extract + exec; the swap changes ONLY the exec target (musl `provision`), never the gate. A tampered tarball still fails closed before any code runs. |
| release payload layout → install.sh `exe=` + registry_cli stage | The `plugin/bin/agentlinux` path is the coupled contract across the producer (Wave 1), the installer exec, and the provisioner stage; a layout mismatch dies "corrupt release?" (fail-closed, not fail-open). |
| curl-pipe (non-interactive) → `provision --yes` | `--yes` grants non-TTY consent for the inherently non-interactive curl-pipe path (Open Q2); the consent is scoped to the install the user explicitly initiated by piping the installer. |
