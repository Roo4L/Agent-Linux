    — create a tmpfile in `dest.parent()` (same dir, so the rename is atomic on
    one filesystem; Pitfall 1), write `body`, `fs::set_permissions` to `mode`,
    `fs::rename(tmp, dest)`, and unlink the tmpfile on every error path (RAII
    guard / explicit cleanup mirroring the Bash RETURN trap). Do NOT use a
    cross-fs temp dir — that loses atomicity.

    `pub fn ensure_line_in_file(line: &str, file: &Path) -> io::Result<()>` —
    read the file (treat absent/unreadable as "no match"), exact whole-line
    compare each line against `line`; if absent append `line` + a single `\n`,
    preserving the existing trailing bytes. Match `grep -Fxq` semantics (literal,
    whole-line).

    `pub fn ensure_marker_block(file: &Path, tag: &str, placement: Placement, body: &str)`
    where `enum Placement { Top, Bottom }`. Compute `begin = format!("# >>> {tag} begin >>>")`
    and `end = format!("# <<< {tag} end <<<")`. Read the existing file (if any)
    and strip lines from `begin` (exclusive of it) through `end` (a line-level
    filter EXACTLY like the awk: a line equal to `begin` starts skipping, a line
    equal to `end` stops skipping, both marker lines are dropped, everything else
    kept). For `Top`: emit `begin\n{body}\n{end}\n` THEN the filtered remainder.
    For `Bottom`: emit the filtered remainder THEN `begin\n{body}\n{end}\n`.
    Write via `write_file_atomic(0o644, ...)`. The emit order + the exact marker
    strings are byte-load-bearing (the `.bashrc`/`CLAUDE.md` bats grep them).

    `pub fn ensure_user(name: &str) -> io::Result<()>` — resolve via
    `nix::unistd::User::from_name(name)`; if `Some`, no-op (NEVER modify an
    existing user). If `None`, run `useradd --create-home --shell /bin/bash
    --user-group <name>` via `Command`. To keep the unit test from mutating

    useradd_argv(name) -> Vec<String>`) the test asserts, and gate the live spawn

    `pub fn ensure_dir(path: &Path, mode: u32, owner: &str) -> io::Result<()>` —

    unconditionally (corrects out-of-band drift — matches the Bash `chmod` +
    `chown` on the else arm).

    `pub fn visudo_validate(file: &Path) -> io::Result<()>` — run `visudo -cf
    <file>`; non-zero → an `Err`.
